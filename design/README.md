# WhoAmI 设计资料

这个目录是 `who-am-i` Skill 的设计资料维护位置。当前内容是讨论稿；具体能力以之后实际发布的 `SKILL.md` 和配套文件为准。

| 文件 | 用途 |
| --- | --- |
| [DESIGN.md](DESIGN.md) | 目标、认识维度、由浅入深的访谈、个人模型、记忆更新规则及待确认问题。设计决策优先更新这里。 |
| [plan-dashboard.html](plan-dashboard.html) | 交互式规划看板，展示维度、访谈路径和阶段进度。 |
| [architecture.html](architecture.html) | 交互式能力架构图，展示输入、Skill 流程、个人数据和使用场景。 |

讨论产生新结论时，先修改 `DESIGN.md`，再同步修改相关 HTML 图示，避免文字和图示表达不同的方案。尚未确定的选择保持标注为讨论稿；不要将用户个人资料写入这个公开 Skill 仓库。
