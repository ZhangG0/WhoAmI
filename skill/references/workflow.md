# 认识、补充与校准

## 极简初始化

档案可以先创建空目录；这不代表已经了解用户。首次使用按以下四问引导，每轮只问一到两个；本轮已经明确回答的问题不重复问。

1. 我应该怎么称呼你？称呼是首次画像唯一必需内容，昵称即可，不要求实名。
2. 你目前主要在做什么？可跳过；作为身份背景或短期状态。
3. 对你来说，目前最重要的是什么？可跳过；只记录用户自述的价值取舍，不自行补充深层动机。
4. 你目前最想实现的目标是什么？可跳过；记录当前目标及用户明确提供的时间。

如果已有档案，先按授权读取可用信息，避免重做初始化。只确认保存一个称呼也能开始使用；其他维度保持未知，不补猜、不显示完成度，也不要求完成八维访谈。称呼保存为 identity/fact，由本次自述事件支持。展示内容与用途，确认后保存；用户拒绝保存时继续普通对话，不宣称档案已完成。

“这次跳过”只在当前会话避开；“不要了解/再问某话题”是明确边界，不能当成待补齐。若用户希望以后也记住该边界，将其作为 preferences 候选单独确认；未保存时不能承诺跨会话记得。不需要保存拒绝背后的敏感原因。

## 八个维度：按当前问题选用

| dimension | 认识什么 | 有价值时怎样追问 |
| --- | --- | --- |
| identity | 身份、角色、当前背景 | 你目前主要承担什么角色？ |
| experiences | 关键经历对人的影响；事件本身保存在 timeline | 哪段具体经历影响了这个选择？ |
| values | 重要原则与冲突时的取舍 | 这两件事不能兼得时，你更愿意保留哪一个？ |
| goals | 当前及长期目标 | 你希望下一阶段有什么变化？ |
| preferences | 沟通、协作与信息偏好，及不希望探索的边界 | 怎样的帮助方式对你最有效？ |
| decisions | 决策依据、风险权衡 | 什么信息会改变你的选择？ |
| patterns | 有多个独立事件支持的行为倾向 | 这是偶发还是在不同情境下也发生过？有没有例外？ |
| relationships | 重要关系、责任与现实约束 | 有哪些现实条件需要优先考虑？不要求透露他人身份。 |

synthesis 是跨维度解释的存放位置，不是第九个必答维度；需要引用来源并保留解释性质。不引入性格测试标签，不从一次情绪推断稳定人格。

## 相关对话中的渐进补充

只在 Skill 被调用且当前任务涉及个人背景时使用此流程；它没有跨应用监听、后台扫描或每轮自动学习能力。

1. 先回应眼前问题。仅当缺少的信息会影响当前回答时，提出一个有实际帮助的问题；不为了填满维度打断用户。
2. 从用户明确提供或授权使用的内容中提取少量候选。值得记住的是未来有用的偏好、目标、约束、关键经历或明确变化；闲聊、重复表达、一次发泄不默认形成长期记忆。
3. 按授权召回相关旧记录，比较陈述、来源、情境和有效时间。同一事件的重复转述不生成独立证据；无法判断时询问，不自动合并。不重新保存无变化的同义陈述。
4. 区分直接自述 fact、短期 state、AI 解释 interpretation、多事件模式 pattern。用户确认解释也不会让它变为事实。
5. 给出简短候选预览及来源，说明保存与召回用途，允许确认部分、修改或拒绝。未确认内容只留在当前会话。按使用契约执行 prepare → 用户确认当前预览 → apply。

示例：“希望 35 岁前实现 FIRE”支持 goals 中的当前目标；“重视自由”和“自主性驱动”都仍是待核实解释，不能因有一句引文就当作明确自述。若用户只想讨论选项，无需为此保存任何一条推断。

## 持续校准

| 情况 | 处理 |
| --- | --- |
| “你之前理解错了” | retract 撤回旧判断；如有明确正确表述，同批新增有来源的新记录。保留真实原始表达，关联解释需要复查。 |
| “以前是这样，现在改变了” | 新事件支持新记录，用 supersede 关联旧记录；旧记录保留为历史。未知的变化日期不猜测。 |
| “今天烦透了，不想干了” | 先理解当下情绪；通常不保存，用户希望记住时作为短期 state，不替代长期目标、不进入长期摘要。 |
| 两句话冲突但原因不明 | 核对时间、情境以及是在纠错还是发生变化；未澄清前不自动覆盖或认定“最新一句正确”。 |
| 记录到了 review_after | 当前任务相关时询问是否仍适用；到期不等于结论相反，也不自动延长有效期。 |
| 重复表达或新增佐证 | 原有内容不变时避免重复记忆。当前没有给旧记录追加证据的专用操作，不通过制造新 ID 假装获得多份独立支持。 |
| 用户要求忘记或停止使用 | 按 forget 或 revoke_grant 的预览确认流程处理，明确外部备份和已发送对话不由此删除。 |

从 FIRE 转向创业时，先询问“终点变了，还是实现自主生活的路径变了”；不能自动把两个目标认定为互斥。语言理解与事件独立性仍由 AI 和用户判断，程序只执行可验证的字段、引用和时间检查。
